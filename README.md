# Қазақтың ұлттық бұйымдары — танымдық ойын (V1)

Веб-игра для детей 5+ на казахском языке: «сиқырлы сандық» (волшебный сундук) открывается, из него по очереди вылетают 6 национальных предметов — **ұршық, жүн, киіз, кілем, қамшы, ою-өрнек**. Для каждого — картинка, название, описание и вопрос детям. В конце — викторина из 3 заданий и финальный экран.

Балаларға арналған танымдық ойын: сиқырлы сандық ашылып, ішінен ұлттық бұйымдар бір-бірден шығады. Әр бұйымның суреті, атауы, сипаттамасы және балаларға сұрақ бар. Соңында — 3 тапсырмадан тұратын ойын.

**Играть / Ойнау:** https://2577ws-glitch.github.io/kazakh-ulttyq-buiymdar/

## Как устроено
- `index.html` — движок игры (HTML/CSS/JS без библиотек). Внутри есть встроенная копия сценария, поэтому игра работает и при открытии двойным щелчком (file://).
- `data.json` — сценарий: тексты, вопросы, викторина, пути к картинкам. На сайте игра читает именно его.
- `images/` — фон, предметы, сундук (корпус + крышка отдельно), эффекты, иконки, орнаменты.
- Режимы: **Тәрбиеші** (дети отвечают вслух, воспитатель жмёт «Келесі») и **Бала**.

## V1 — что нового
- Настоящая анимация сундука: сундук покачивается, светится, трясётся, крышка поднимается и съезжает в сторону, разлетаются звёзды, затем 6 предметов по одному вылетают из сундука и встают в ряд.
- Карточка урока: предмет «поднимается» из сундука со свечением и звёздами; крупно — название, описание, вопрос детям; разделитель-орнамент; кнопка повтора анимации.
- Декор: клубки шерсти (жүн), свёрнутый киіз (киіз), свёрнутый кілем (кілем).
- Викторина: конфетти и звёзды за правильный ответ, «встряска» за неправильный, звёзды-награды копятся.
- Финал: дождь из конфетти и звёзды.
- Звук без файлов (WebAudio): перезвон при открытии сундука, «поп» предметов, сигнал успеха, мягкий сигнал ошибки, фанфары. Кнопка 🔊 включает/выключает эффекты, кнопка ♫ — тихую синтезированную мелодию (alert убран).
- Угловые орнаменты во всех 4 углах, иконки звука/музыки/повтора.
- Прогресс считается по длине данных (не захардкожен 6/3); все подписи — в `data.json`.
- Адаптивно: ноутбук/проектор (16:9 и 4:3) и телефон.
- Метка версии «V1».
